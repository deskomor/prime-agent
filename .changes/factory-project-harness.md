- Local harness refinement is now saved per project instead of per session. `/refine` and auto-refine write to `<agent dir>/projects/<key>/harness`, which every session in the same git repository (all its worktrees) reads, so a lesson learned in one session reaches the next. Refinement history and verdicts are kept there too, so `/refine rollback` works from any session of the project. `--global` is unchanged. A `/refine --probe` run still sees only its seed. Session stores written before this change stay on disk and are no longer read.
