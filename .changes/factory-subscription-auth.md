- `prime-agent auth-gateway serve` turns your logins (API keys, a Claude Pro/Max login or a ChatGPT login) into a local OpenAI chat-completions endpoint on 127.0.0.1, behind a bearer token from `prime-agent auth-gateway token`, so a tool that only speaks the OpenAI wire format, such as a benchmark judge, can use them without seeing a provider token. A symlinked `auth.json` is now followed on write, so an isolated agent dir can share your logins and their token refreshes.
