- `/refine --probe [--task "..."]` tests a refinement before keeping it: it replays a task from the conversation twice as subagents in throwaway git worktrees, once on the current harness and once with the proposed edits, then keeps only the edits the second run supports and records a verdict for each. The runs inherit the session's host hooks and tool permission; they cost about two to three times the replayed task. `refine.probe.enabled: true` makes every manual `/refine` probe, and `refine.probe.timeoutMs` (default 15 minutes) bounds each run.
