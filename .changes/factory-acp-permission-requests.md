- ACP clients can now approve tool calls: a client that sets `clientCapabilities._meta["ai.primeintellect.prime-agent"].toolPermissions = true` at `initialize` gets a `session/request_permission` request before each main-agent tool call runs (allow or reject, once or always). A rejected, cancelled, errored or unanswered request (30 minutes) denies the call. Clients that do not opt in keep the ungated behavior.
