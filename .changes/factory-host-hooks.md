- ACP clients can now install awaited host hooks: listing `hooks` (`after_tool_call`, `host_call`) under `clientCapabilities._meta["ai.primeintellect.prime-agent"]` at `initialize` makes the session send each hook as an `_ai.primeintellect.prime-agent/hook` request. `after_tool_call` sees every tool result and can replace it (no usable answer keeps the result); `host_call` decides kernel host calls such as `rlm.spawn` (wire type `rlm.run`) before they run, filtered by optional `hostCallTypes`, and refuses the call on a refusal, an error, or no answer within `hookTimeoutMs` (default 30 s). Sessions without hooks behave as before.
- More optional host hooks, each continuing as if absent on an error, a timeout, or no usable answer: `before_agent_start` (sees `{prompt, systemPrompt, imageCount}` before the prompt is saved; `{appendSystemPrompt}` extends that run's system prompt), `turn_end` (sees `{message, toolResults}` after each turn; `{messages}` adds hidden custom rows that are saved and read by the next model call), `context` (sees `{purpose, messages: [{entryId, message}]}` for the `provider`, `budget`, `compaction`, `branch_summary` and `refine` reads; `{messages}` replaces what that read sees), `session_before_compact` and `session_before_tree` (`{cancel: true}` cancels, `{summary}` replaces the generated summary), `message_end` and `user_bash_end` (notifications).
- ACP clients can append durable custom session entries with `_ai.primeintellect.prime-agent/append_session_entry` (`{sessionId, customType, data?}`, answers `{entryId}`) and pause or resume the session's own auto-refinement with `_ai.primeintellect.prime-agent/set_auto_refine` (`{sessionId, enabled}`). The daemon gains the matching `append_session_entry` and `set_auto_refine` commands.
