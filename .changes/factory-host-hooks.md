- ACP clients can now install awaited host hooks: listing `hooks` (`after_tool_call`, `host_call`) under `clientCapabilities._meta["ai.primeintellect.prime-agent"]` at `initialize` makes the session send each hook as an `_ai.primeintellect.prime-agent/hook` request. `after_tool_call` sees every tool result and can replace it (no usable answer keeps the result); `host_call` decides kernel host calls such as `rlm.spawn` (wire type `rlm.run`) before they run, filtered by optional `hostCallTypes`, and refuses the call on a refusal, an error, or no answer within `hookTimeoutMs` (default 30 s). Sessions without hooks behave as before.
